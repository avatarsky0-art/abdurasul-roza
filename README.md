```bash
python -m http.server 8090 --bind 127.0.0.1 --directory toy-abdurasul-roza
```

## Өзгөртүү керек болгон жерлер

### 1. Музыка (коюлду ✓)
`assets/music.mp3` — 1:06. Баскыч басылганда ойнойт, биринчи тийгенде өзү да коюлат.
Алмаштыруу керек болсо — ошол эле ат менен үстүнө жазыңыз.

### 2. RSVP жооптору кайда барат
`script.js` файлынын башындагы `CONFIG` бөлүгү:

```js
whatsapp: '996700123456',          // плюссуз, боштуксуз
telegram: { botToken: '', chatId: '' }
```

- **WhatsApp** — эң жөнөкөйү. Номер жазылса, конок «Жоопту жөнөтүү» баскычын басканда
  даяр билдирүү менен WhatsApp ачылат, конок өзү жөнөтөт.
- **Telegram бот** — жооп автоматтык түрдө келет, конок эч нерсе кылбайт.
  `@BotFather` ден бот түзүп, `botToken` жана өзүңүздүн `chatId` жазыңыз.
  Эскертүү: токен сайттын кодунда ачык турат, ошондуктан бул ботту башка эч нерсеге
  колдонбоңуз.
- Экөө тең бош болсо — жооп браузердин `localStorage` ичинде гана калат.

Конок жөнөткөн жооп мындай келет:

```
💌 Той: Абдурасул & Роза
Конок: Залкар
Жообу: Келем
Киши саны: 3
```

### 3. Узор картинкалары (коюлду ✓)

| Файл | Кайда колдонулат |
|---|---|
| `assets/orn-band.webp` | башкы сүрөттүн ылдыйкы жана беттин эң аяккы көк кашаты |
| `assets/orn-tile.webp` | бөлүмдөрдүн капталындагы өңү кеткен медальондор |
| `assets/orn-edge.webp` | бөлүмдүн башындагы ачык көк чачы |
| `assets/heart-plain.webp` | календарда 9-ноябрды белгилеген жүрөк |
| `assets/orn-heart.png` | оюулуу жүрөктүн баштапкы сүрөтү (сайтта SVG версиясы) |

Алмаштыруу керек болсо — `style.css` башындагы `--orn-band`, `--orn-tile`,
`--orn-edge` саптары. Жаңы картинка үчүн промпттор `УЗОР-ПРОМПТ.md` файлында.

Жүрөк **SVG** кылып кайра тартылган (`index.html` башындагы `<symbol id="heart">`),
ошондуктан түсүн CSS'тен өзгөртсө болот: бөлгүчтөрдө — контур, формада — толук көк
ичи ак оюу менен, календарда — жөнөкөй контур.

### 4. Шрифттер
Баары Google Fonts'тон, кыргыз тамгаларын (ң, ө, ү) толук колдойт:
**Prata** (баш тамга), **Cormorant Garamond** (текст), **Marck Script** (көк
каллиграфия — аттар), **Montserrat** (форма).

Эскертүү: Playfair Display кыргыз тамгаларын колдобойт, Great Vibes'тин кириллица
«А» тамгасы туура эмес жана тамгалары бири-бирине кирет — ошондуктан экөө тең
алынып салынды. Google Fonts'то кириллицаны колдогон каллиграфия шрифти бары-жогу
беш-алтоо, алардын эң тазасы — Marck Script.

### 5. Сүрөттөр
`assets/hero.webp` (башкы) жана `assets/couple.webp` (ортодогу). Алмаштырсаңыз,
ошол эле аттар менен коюңуз.

## Интернетке чыгаруу — GitHub Pages

Netlify'дын акысыз планында беттин ылдыйында «Powered by Netlify» белгиси чыгат.
GitHub Pages'те андай белги жок жана ал дагы акысыз.

Репозиторий даяр (`git init` + биринчи commit жасалган). Кийинкиси:

**1. GitHub'та бош репозиторий түзүңүз**

[github.com/new](https://github.com/new) → аты `abdurasul-roza` → **Public** →
README/`.gitignore`/лицензия кошпоңуз (бош болушу керек) → Create repository.

**2. Компьютерден түртүңүз** (`ЖАЗУУЧУ-АТЫ` деген жерге GitHub логиниңизди жазыңыз):

```bash
cd C:/Users/Zalka/Documents/Portfolio_Site/toy-abdurasul-roza && git remote add origin https://github.com/ЖАЗУУЧУ-АТЫ/abdurasul-roza.git && git push -u origin main
```

**3. Pages'ти күйгүзүңүз**

Репозиторийде **Settings → Pages** → *Source*: **Deploy from a branch** →
*Branch*: **main**, папка **/ (root)** → **Save**.

1–2 мүнөттөн кийин сайт даяр:

```
https://ЖАЗУУЧУ-АТЫ.github.io/abdurasul-roza/
```

**Кийин өзгөртүү киргизсеңиз:**

```bash
cd C:/Users/Zalka/Documents/Portfolio_Site/toy-abdurasul-roza && git add -A && git commit -m "озгортуу" && git push
```

Бир мүнөттөн кийин сайт өзү жаңыланат — кайра таштоонун кереги жок.
