# Кара-ак улуттук шаблон — той чакыруу

Бир беттик чакыруу. Папка жок — бардык файл бир катмарда.

```
index.html   ← баары ушул жерде (HTML + CSS + JS)
bw3.jpg      ← башкы сүрөт (hero)
bw1.jpg      ← ортоңку сүрөт
bw2.jpg      ← аяккы сүрөт
song.mp3     ← музыка
```

## Бөлүктөрү
Башкы сүрөт → саламдашуу → той ээлери → күнү жана календарь →
кери саноо → башталуу убагы → той өтүүчү жай (2GIS) →
**сүрөт блогу** (той программасынын ордуна) → WhatsApp аркылуу жооп → аяктоо

## GitHub Pages
1. Жаңы Public репозиторий → Add file → Upload files → 5 файлды тең сүйрөп таштa → Commit
2. Settings → Pages → Branch: `main` / `root` → Save
3. 1-2 мүнөттөн кийин: `https://колдонуучу.github.io/репозиторий/`

## Эмнени өзгөртүү керек

`index.html` ичиндеги `<script>` бөлүгүнүн башындагы **CONFIG**:

| Сап | Эмне |
|---|---|
| `toyDate` | той башталчу убакыт. **Ай 0дон башталат:** 10 = ноябрь |
| `calYear / calMonth / calDay` | календарда жүрөкчө коюлчу күн |
| `whatsapp` | той ээсинин номери — `996550581583` түрүндө, `+` жана боштуксуз |
| `waPrefix` | WhatsApp'ка түшчү билдирүүнүн башталышы |

Калгандары `index.html` ичинде түз текст менен турат:
аттар, той ээлери, дарек, убакыт, цитата.
2GIS шилтемеси `🔻` белги коюлган жерде.

Түстөр `<style>` ичиндеги `:root`:
`--accent` — оймо жана жүрөкчөнүн түсү (азыр көгүш `#8097c9`).

Сүрөттөрдү ошол эле аттар менен алмаштыр (`bw1.jpg`, `bw2.jpg`, `bw3.jpg`) —
тик (вертикалдуу), жүз көрүнбөгөн, 900px'тен кем эмес.
Кара-ак эффект CSS'те автоматтык түрдө коюлат, түстүү сүрөт берсең да болот.

## Конок кантип жооп берет
Атын жазат → «Келем / Жубайым менен келем / Келе албайм» тандайт →
«Жоопту жөнөтүү» баскычы WhatsApp'ты даяр текст менен ачат:

```
Той чакырууга жооп
Аты-жөнү: Айбек Усонов
Жообу: Жубайым менен келем
```
